# noexit web UI

`noexit.html` is a single self-contained file: open it by double-clicking, or serve it from anywhere. The analysis engine
runs in a Web Worker inside the page; nothing is uploaded. Rebuild after changing `src/` or `samples/` with `npm run web`.

Hosted copy (GitHub Pages, built from `master` by `.github/workflows/pages.yml`): enable *Settings → Pages → Source: GitHub Actions* once.
